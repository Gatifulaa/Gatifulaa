## 🚀 Meu Projeto Principal: UincOS

Uma distribuição Linux pensada para quem quer performance extrema sem abrir mão da estética.

- **🎨 Interface:** Fusão perfeita entre a usabilidade do macOS e as diretrizes de design Adwaita.
- **🛡️ Arquitetura:** Sistema operacional **Imutável**, garantindo estabilidade vitalícia e segurança contra modificações acidentais.
- **⚡ Performance:** Kernel otimizado e processos enxutos para máxima resposta de hardware.

### 📦 O Ecossistema Una
Cansado dos gerenciadores comuns, estou desenvolvendo o **Una**, o coração da distro:
- **Gerenciador:** `una -i [pacote]` — Simples, rápido e atômico.
- **Extensão Própria:** Arquivos **`.uic`**, um formato de pacote otimizado para compatibilidade e isolamento.
